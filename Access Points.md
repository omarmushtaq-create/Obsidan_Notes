1. Wireless Technologies
    
    - **Wireless technologies** use **radio waves** as the transmission medium.
        
    - Radio systems use **transmission and reception antennas** to send and receive signals.
        
    - These antennas are **tuned to a specific frequency** so they can transfer the signals.
        
    
    ## Wi-Fi and WLANs
    
    - Most **WLANs (Wireless Local Area Networks)** are based on the **IEEE 802.11 standards**, also known as **Wi-Fi**.
        
    - Most Wi-Fi networks use **Infrastructure Mode**.
        
        - In Infrastructure Mode, each client device, called a **station**, connects to the network through an **access point (AP)**.[^1]
            
    
    ## Basic Service Set (BSS)
    
    - In **802.11 documentation**, an Infrastructure Mode network is called an **Infrastructure Basic Service Set (BSS)**.
        
    - The **MAC address of the AP's radio** is used as the **Basic Service Set Identifier (BSSID)**.
        
    
    ## Access Points and Wired Networks
    
    - An **access point (AP)** can create a **wireless-only network**.
        
    - An AP can also work as a **bridge** between:
        
        - Wireless stations
            
        - A wired network
            
    - The wired network is called the **Distribution System (DS)**.
        
    - The AP connects to the network in a similar way to a host computer:
        
        - It connects to a **wall port**.
            
        - The wall port is connected by cable to an **Ethernet switch**.
            
    - In an **enterprise network**, the AP will likely use **Power over Ethernet (PoE)**.
        
        - PoE allows the AP to get **power through the data cable**.
            
    
    [^1]: A device that provides a connection between wireless devices and can connect to wired networks, implementing an infrastructure mode WLAN.
