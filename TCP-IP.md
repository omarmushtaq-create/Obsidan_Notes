## What is a Protocol?
- A **protocol** = set of rules that lets networked hosts communicate in a **structured format**
- Multiple protocols often work together = a **protocol suite**

---

## TCP/IP
- Most networks use the **Transmission Control Protocol / Internet Protocol (TCP/IP)** suite
- This is the **standard** protocol suite for modern networking

---

## Layers and Encapsulation

### Layers
- Network functions are divided into **layers**
- Each layer has protocols responsible for a specific job

### Encapsulation
- Lower-layer protocols **encapsulate** data from higher-layer protocols
- Each protocol **adds its own header** to the data it carries from the layer above

> Think of it like nesting envelopes: each layer wraps the previous layer's data inside its own "envelope" (header) before passing it on.

---

## Quick Summary
- Protocol = rules for structured communication
- Protocol suite = group of protocols working together (e.g., TCP/IP)
- Networks are organized in **layers**
- **Encapsulation** = lower layers wrap/add headers to upper-layer data
