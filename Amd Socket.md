AMD traditionally uses Pin Grid Array (PGA) sockets, where the pins are located on the CPU itself and fit into the motherboard socket. AMD has transitioned to Land Grid Array (LGA) sockets, where the bottom of the CPU features flat contact points instead of pins.Key AMD socket types include:

- AM4: Widely used for AMD's Ryzen processors, providing compatibility across multiple generations. AM4 uses the PGA socket design (pins on the CPU).
    
- TR4: Designed for Threadripper CPUs, catering to high-performance desktop applications. TR4 uses the LGA socket design.
- SP3: Used for AMD's EPYC server processors, which utilize LGA sockets for enhanced durability and performance.
