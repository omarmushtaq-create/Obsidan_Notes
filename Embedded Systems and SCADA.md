

## Embedded Systems

### What They Are
- An **embedded system** = electronic device built to do **one specific, dedicated function**
- Can range from **small/simple** to **large/complex**:
  - Small: microcontroller in an **IV drip-rate meter**
  - Large: **industrial control system** running a **water treatment plant**

### Network Considerations
- Traditionally designed for **closed networks**
  - All elements known to the vendor
  - **No connection** to wider computer networks
- When embedded systems **do** connect to data networks:
  - Need **special network design/support considerations**
  - **Security** is the biggest concern

## ICS (Industrial Control System)

### Purpose
- Provides **workflow and process automation**
- Controls machinery for **critical infrastructure**:
  - Power suppliers
  - Water suppliers
  - Health services
  - Telecommunications
  - National security services

### ICS Components

| Component | Role |
|-----------|------|
| **PLC** (Programmable Logic Controller) | Embedded controller in plant devices/equipment |
| **Actuators** | Operate **valves, motors, circuit breakers**, and other mechanical parts |
| **Sensors** | Monitor local conditions (e.g., **temperature**) |
| **HMI** (Human-Machine Interface) | Used to view output/configure a PLC (local control panel or software on a computer) |
| **Control loop** | Where PLCs are connected together |
| **Control server** | Governs the entire process automation system |
| **Data historian** | **Database** of all info generated by the control loop |

### OT vs IT Networks
- An embedded system network = **Operational Technology (OT) network**
- Called this to **distinguish it from an IT network**

## SCADA (Supervisory Control and Data Acquisition)

### What It Does
- **Replaces the control server** in **large-scale, multi-site ICSs**
- Typically runs as **software on ordinary computers**
- **Gathers data from and manages** plant devices/equipment with embedded PLCs
  - These are called **"field devices"**

### Connectivity
- Uses **WAN communications** to link the SCADA server to field devices:
  - **Cellular**
  - **Satellite**

---

## Note: Risks of Legacy/Embedded Systems
- Both **legacy** and **embedded** systems = risk for:
  - **Maintenance**
  - **Troubleshooting**
  - **Security**
- They need **more specialized knowledge** than regular off-the-shelf systems
- Experts in these systems are **highly sought after**

## Quick Summary

| Term | Meaning |
|------|---------|
| **Embedded system** | Device built for one dedicated function |
| **ICS** | Controls machinery in critical infrastructure (power, water, etc.) |
| **PLC** | Embedded controller inside plant equipment |
| **HMI** | Interface to view/configure a PLC |
| **Data historian** | Database of all control loop data |
| **OT network** | Embedded system network (vs IT network) |
| **SCADA** | Control system for **large, multi-site** ICS; uses WAN (cellular/satellite) to reach field devices |
